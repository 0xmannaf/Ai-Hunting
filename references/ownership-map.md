# Ownership Map — File Governance & Responsibility

- **Version:** 1.0
- **Last Updated:** 2026-10-01
- **Purpose:** who owns every file, and the modification policy that governs
  it.

## Core principle

- Shared knowledge is **immutable**.
- Runtime files are **orchestration-only**.
- **No duplication** — one canonical source per artifact; runtime copies are
  generated, never hand-edited.

## Table 1 — Shared knowledge (immutable, root level)

| File | Owner | Purpose | Modification policy |
|------|-------|---------|---------------------|
| `agent-briefing.md` | /update pipeline | current knowledge state | updated via /update ONLY; manual edits are overwritten |
| `AGENTS.md` | human | constitution | DO NOT MODIFY (human amendments only) |
| `prioritization.md` | human | signal engine P1-P4 | DO NOT MODIFY (human amendments only) |
| `skills/master-bugbounty-rules.md` | human | foundation rules | DO NOT MODIFY; runtime copy regenerated by hand-sync |
